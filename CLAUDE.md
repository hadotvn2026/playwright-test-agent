# Project Context (Playwright TypeScript)

Playwright Test end-to-end suite in strict TypeScript, organised as a Page Object Model built around **complete user behaviours**.

- Adding or changing a page object, spec, fixture or helper: read `CODING_STANDARDS.md` first.
- Working a GitHub issue, or opening or updating its PR: follow the `agent-implement` skill (`/agent-implement [N]`); labels, CI checks and one-time setup are in `docs/agent-workflow.md`.
