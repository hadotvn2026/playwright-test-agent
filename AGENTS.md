# Agent instructions

- Adding or changing a page object, spec, fixture or helper: read `CODING_STANDARDS.md` first; it defines *behaviour methods* and when the change is done.
- Working a GitHub issue or its PR: follow `.claude/skills/agent-implement/SKILL.md` (a human starts it as `/agent-implement [N]`). Labels, CI checks and one-time setup: `docs/agent-workflow.md`.
- Code in `pages/`, `tests/`, `fixtures/` and `utils/` holds no comments of any kind (see `CODING_STANDARDS.md`).
